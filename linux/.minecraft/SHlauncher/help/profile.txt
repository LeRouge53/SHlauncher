Usage: profile <Instruction> [username]:

The profile command allow to create, remove and select profiles used to play the game.

Instructions :
	"profile help" : Print this help
	"profile list": List all avariable profiles (selected or not)
	"profile login": Create a prenium profile using a microsoft account (PLANNED)
	"profile create <username>" : create a profile with the username
	"profile select <username>" : select the profile corresponding to the username
	"profile switch <username>" : alias of "profile select"
	"profile remove <username>" : delete the profile corresponding to the username
